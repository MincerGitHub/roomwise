# 真实训练与实验记录（2026-10-11）

已经训练出一个可加载、可实际推理的卧室家具位置/朝向调整模型。它在模拟扰动测试中，比简单裁剪规则更接近参考布局；它的原始输出仍经常有越界，因此应用继续使用独立几何检查和修复。这次实验没有证明混合模型优于规则布局的用户体验。

## 1. 实际训练

模型是自行实现的 set Transformer：隐藏维度 64、2 层、4 个注意力头，共 73,604 个参数。只预测家具的位置和朝向修正量，家具身份、数量、尺寸与外观模型均由原始场景记录保持。

使用 LEGO-Net 作者预处理的 3D-FRONT 卧室数据，共 5892 个非增强房间。原始尺寸为半尺寸，读取时乘 2。按住宅编号划分 4514 个训练房间、696 个验证房间、682 个测试房间；住宅交集为 0。先划分住宅，再在线生成扰动。训练含随机锁定物品与不同程度的旋转/位置扰动。

实际 CPU 训练合计 144 轮、5184 步、278.5 秒，分两阶段，第二阶段在连续 12 轮没有更好的验证分数后停止。最终采用第 132 轮 checkpoint，SHA256 为 `38da9124acb334253d2d02f88a083c390953488bd86a4bea42ed5978e4058dde`。测试集不参与训练、阈值或 checkpoint 选择。

可核查文件：`../models/layout_denoiser.json`、`data_manifest.json`、`training_history.json`、`training_curves.png`。训练命令与固定依赖见 `../../backend/scripts/README_training.md`。

## 2. 未见住宅的模拟扰动测试

测试有 682 个房间、498 个住宅。以专业设计布局为参考，对可移动物品加入固定种子的随机位置和角度扰动，再评价恢复程度。参考是一个合理示例，并不代表唯一最佳设计。

| 位置扰动标准差 | 输入位置误差 | 简单裁剪＋90°吸附 | 模型三步位置误差 |
|---|---:|---:|---:|
| 0.20 米 | 0.252 米 | 0.196 米 | 0.159 米 |
| 0.45 米 | 0.564 米 | 0.425 米 | 0.229 米 |
| 0.80 米 | 0.992 米 | 0.713 米 | 0.428 米 |

中等扰动（位置标准差 0.45 米、角度标准差 30°）下，模型三步将相对参考的位置平均误差降低约 59.34%，角度平均误差由 23.96° 降至 7.77°。这是模拟恢复误差，不是实际搬家满意度、可行方案成功率或尺寸测量误差。

**必须同时报告的不足：**中等扰动下，原始模型有 36.96% 的物品包围盒占地超出地面轮廓，简单裁剪规则为 4.62%。模型占地重叠对比例为 15.25%，规则为 18.75%；源参考布局的完整包围盒本身也有 12.27% 的重叠对，部分可能来自椅子与桌子、形状空隙或有意接触。该重叠指标不能直接解释为真实网格碰撞率。

无扰动输入上，模型三步仍平均移动可移动物品 0.134 米，角度改变 3.23°。因此已满意的布局应由用户选择是否重排；不能宣称模型自动保持所有未锁定位置。锁定位置和朝向在测试中变化量为 0，是程序强制保护的结果。

逐类别数量与误差均保存在 `heldout_metrics.json`。数据较偏向床、床头柜和衣柜，测试咖啡桌仅 2 件，不能用总体数字声称所有家具类别都同样可靠。`heldout_examples.png` 是实际固定测试样本，不是人工挑选的最好案例。

此处规则基线只做边界裁剪和角度吸附，**不是应用的完整多次搜索布局器**。完整应用的结果另见下一节。

## 3. 应用规则与混合流程对照

采用 12 个自制工程场景：10 个普通组合与 2 个应失败条件（家具明显大于房间、锁定衣柜位于房外）。两组对同样的场景使用 seed=712，单次最多 5 秒、8000 次放置检查、请求 1 个候选。失败不删除家具、不缩小尺寸、不解锁。

| 项目 | 规则搜索 | 模型＋几何修复 |
|---|---:|---:|
| 普通场景找到合格方案 | 10/10 | 10/10 |
| 应失败条件正确拒绝 | 2/2 | 2/2 |
| 身份、尺寸、锁定变化违规 | 0 | 0 |
| 返回方案未通过独立检查 | 0 | 0 |
| 平均耗时（含两例失败） | 0.324 秒 | 0.482 秒 |

混合流程共提出 12 次模型建议，原始模型直接通过为 0 次，几何修复后通过为 10 次；本组没有规则回退候选。因此这组证明的是流程能完成、约束能保护、失败能明确返回，**没有证明模型独立输出可用，也没有证明混合流程成功率或耗时优于规则。**

原始逐次数字在 `app_metrics.json`；自制场景在 `app_scenarios.json`。计时受 CPU 负载影响。样本数量有限，未开展真实用户偏好或操作时间试验。

## 4. 当前证据支持的范围

可以说明：自行训练的模型可用于恢复被打乱的卧室家具位置；应用能将模型建议与明确规则检查结合，并保持旧家具身份、尺寸和锁定状态。

尚未验证：任意新家具组合、精确照片重建、全屋联合设计、自然语言入口优于鼠标、真实搬家用户节省时间、建筑规范或真实柜门操作可达性。数据缺少用于上述结论的对应标签。
