# 智能交互与布局升级方案

2026-10-20。本文区分本轮已接入的能力、已暴露的问题与后续验收，不把接口接通等同于软装设计合格。

当前已接入 DeepSeek API，用户已在本机填写密钥，完成三次真实调用。仅发送文字和房间/家具结构信息，不发送照片或网格；接口会计费。证据见 `artifacts/interaction_checks/deepseek_live_commands.json`，配置与关闭方式见 [接入说明](DeepSeek接入说明.md)。

## 为什么现在不好用

升级前聊天依靠关键词和正则，不是大语言模型。“书架靠墙”不在动作表中就会失败。现有 73,604 参数模型学习的是位置去噪，不负责中文理解，也没有学过审美偏好。继续补几个关键词解决不了大量不同说法。

## 怎么改

1. **先理解需求**：接入成熟语言模型，把中文转成有限的动作表；结合家具名称、选中对象、门窗和最近指令，识别对象、否定、范围、单位。不明确就问清楚。先覆盖约 20 类常见操作，不能承诺理解任意指令。
2. **检查能否执行**：模型输出须符合 JSON 结构，对象必须真实存在，动作必须已实现。“识别出需求”和“已执行成功”分开显示。颜色、风格等未实现动作不能静默忽略。
3. **成组布置**：普通规则/混合生成已先尝试床头靠墙、床头柜靠床头侧、桌椅相对、柜背靠墙的模板，再搜索其他候选；明确局部要求绕开整屋模板，优先保留未提及家具，必要的额外移动逐项说明。这些是规则来源，不是网络推理。沙发茶几等更多关系、功能区和相对距离还需扩展；默认模板不能代替每个家庭的实际需要。
4. **独立验收**：家具身份、尺寸、锁定、房间边界、碰撞、入口与每条明确要求分别验收。失败时说清哪一项未满足。评分只排序，不能替代验收。
5. **验证是否好看**：使用俯视图和三维图，由不知道方案来源的人比较功能、通行、搭配和整体协调。颜色与风格还需要真实材质、资产标签和偏好数据，现有示意块不能完成专业软装设计。

语言层已支持可切换接口，当前使用 DeepSeek，不从零训练语言模型，也不让模型直接任意修改坐标。已有布局模型作为候选来源，保留规则与约束优化对照。

三次真实调用中，“书架靠墙”对象与动作正确；另一句把“衣柜保持原位”误作保留，现增加漏锁拒绝保护；第三句明确移动却被旧执行器分流为生成，现已修正为编辑。修复后未再次付费调用，不能报告“3/3准确”或多数指令覆盖率。

## 如何证明改好了

配套 `data/interaction_benchmark_v1.jsonl` 是自制公开测试材料，包含固定场景快照和显式变更。开发集用于调整，验收集只在冻结提示词后运行；因材料公开且由开发者编写，仍需另收未见说法和真实体验反馈，不能当独立盲测。

分别报告：动作与对象解析准确率、歧义澄清、未支持动作的明确拒绝、单位和否定正确率；再报告布局中需求全部满足率、无关家具移动量、耗时和人工偏好。JSON 合法不等于理解正确，无碰撞不等于实用，更不等于好看。模拟接口测试只验证连接流程；三次工程样例不足以报告模型准确率。自动回归在 `disabled` 后端8766运行，避免误计费。

校验材料：`python backend/scripts/evaluate_language_plans.py --split all`。仅输出场景完整性检查，不调用模型。添加 `--predictions 文件.jsonl` 可对比外部语义标注；预测须先转成评测规范，并保留真实接口调用记录。`planned` 是本轮升级前尚缺能力，新增执行器后再更新版本，不能混算识别率。

## 依据与边界

- [DeepSeek JSON 输出](https://api-docs.deepseek.com/guides/json_mode/)：提供 JSON 格式输出，仍需程序校验对象、能力和约束，不能把格式正确当成需求理解正确。
- [Holodeck，CVPR 2024](https://openaccess.thecvf.com/content/CVPR2024/papers/Yang_Holodeck_Language_Guided_Generation_of_3D_Embodied_AI_Environments_CVPR_2024_paper.pdf)：研究语言引导的三维环境生成；支持分解语言与空间规划的方向，不证明本项目已达到同等效果。
- [Ollama 结构化输出](https://docs.ollama.com/capabilities/structured-outputs)：可用 JSON Schema 约束输出格式；不保证语义正确，文档当前说明其云端不支持该功能。
- [Qwen3-4B-Instruct-2507 官方模型卡](https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507)：提供开放权重和部署说明，可作为候选；本项目效果和显存占用仍须实测。

本轮已接入语言理解、补充基础成组模板并修复执行分流；更多场景关系、真实指令评测与人工偏好校准仍待完成，不能只更换语言模型就宣称可替代设计师。
